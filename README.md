# SmartQueue – Queue Management System

SmartQueue is a web-based Queue Management System developed using Python, Flask, MySQL, HTML, CSS and JavaScript.

The main purpose of this project is to make queue management easier and reduce the time customers spend waiting in long queues at banks, offices and service centres.

## Features

- User Registration and Login
- Customer Dashboard
- Token Generation
- Live Queue Status
- Estimated Waiting Time
- Admin Dashboard
- Token Management (Complete / Skip)
- Counter Management
- Reports and Analytics

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure

- app.py – Main Flask application
- templates/ – HTML pages
- static/ – CSS files
- requirements.txt – Required Python libraries
